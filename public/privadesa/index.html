02 / FINALITAT I BASE JURÍDICA

ATENDRE LA TEVA CONSULTA.

Les dades facilitades mitjançant el formulari o pels canals de contacte s’utilitzen per respondre consultes, preparar una conversa comercial o gestionar una sol·licitud iniciada per tu. La base jurídica és el teu consentiment i, quan correspongui, l’aplicació de mesures precontractuals a petició teva.

03 / CONSERVACIÓ I DESTINATARIS

NOMÉS EL TEMPS NECESSARI.

Les dades es conservaran durant el temps necessari per atendre la consulta i, si s’inicia una relació professional, durant els terminis aplicables a aquesta relació. No es preveu cedir dades a tercers excepte quan sigui necessari per prestar el servei o per obligació legal.

04 / DRETS

TU DECIDEIXES SOBRE LES TEVES DADES.

Pots sol·licitar accés, rectificació, supressió, oposició, limitació o portabilitat escrivint a lab@desorden.cat. També pots retirar el consentiment en qualsevol moment i presentar una reclamació davant l’autoritat de protecció de dades competent.
